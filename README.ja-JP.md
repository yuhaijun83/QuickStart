# QuickStart
よく使うプログラムやコマンドを一つに集めたクイック起動ソフト。

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · **日本語** · [English](README.en-US.md) · [한국어](README.ko-KR.md)

【ビルド環境】：

       Windows 11 Enterprise 26H2 (Cn) + Visual Studio 2026 Enterprise + .Net FrameWork 4.8

【実行要件】：

   .Net FrameWork 4.7.2 以上のインストールが必要（Windows 10 LTSC 2019/2021 は標準搭載；それより古い OS は手動インストール）

   Download Url: [.NET Framework 4.7.2 ダウンロードページ](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net472)

【使い方】：
  
       1.ini 設定ファイルを編集すれば、実行プログラムの起動情報をいつでも変更できます。
       
       2.ini ファイルの変更は自動的に反映されます：プログラムは実行中常に ini ファイルを監視し、
         外部で変更・保存されると約 1 秒以内に自動的に再読み込みしてボタンを更新します
         （名称、表示、有効/無効、色、プログラムパス、順序など）。再起動は不要です。
       
       3.ini ファイルで設定された表示ボタン数に応じて、ボタンを順番に自動表示します。1 行最大 8 個、超過分は次の行に自動表示。
       
       4.ボタンは最大 8 行・計 64 個まで表示でき、64 個を超える設定は無視されます。
         旧版 ini（最大 48 ボタン）は起動時に不足の [Button_49]~[Button_64] セクションを自動補完（既定は非表示）。

       5.簡体字中国語、繁体字中国語、日本語、韓国語、英語の 5 言語に対応しています。
       
       6.QQ ウィンドウに似た、画面端へのスナップ（ドッキング）機能に対応しています。
  
       7.ini ファイル設定例：
        #############################################
        # [Button_01] - [Button_64] 最大 64 ボタンまで対応、64 を超えると無視（変更不要）
        [Button_XX]
        # ボタン表示名【</br>、<br>、<br/> または \n で改行表示できる；1行に収まらない文字は空白の位置で自動で改行され、行数がボタンの高さを超える場合は末尾に ... を表示】
        Button_Name=
        # ボタン表示の有無【1：表示；1 以外は非表示；既定：空 非表示】
        Button_Visible=
        # ボタン有効/無効【1：有効；1 以外は無効；既定：空 無効】
        Button_Enable=
        # ボタン背景色【設定値は英語の単語】（Sample_ini/Color.html の色名を参照）
        Button_BackColor=
        # ボタン文字色【設定値は英語の単語】（Sample_ini/Color.html の色名を参照）
        Button_TextColor=
        # 起動プログラムのフルパスとプログラム名
        Program_Name=
        # 起動タイプ【exe：exe 実行ファイル；cmd：cmd コマンドまたは *.cmd、*.bat 実行ファイル；既定：exe】
        Program_Type=
        # 起動引数
        Program_Param=
        #############################################

        [Button_01]
        Button_Name=Eclipse<br/>v4.21
        Button_Visible=1
        Button_Enable=1
        Button_BackColor=GreenYellow
        Button_TextColor=OrangeRed
        Program_Name=D:\Eclipse_4.21\eclipse.exe
        Program_Type=exe
        Program_Param=-clean

      8.システムトレイのメニューから、自動起動の設定ができます。

      9.本プログラムは同時に 1 つのインスタンスのみ起動できます。（複数起動する場合はフォルダごとコピーし、コピー後の exe ファイル名を変更してください）

      10.ボタンの背景色、文字色を設定できます。（Sample_ini/Color.html の色名を参照）

      11.ドラッグ＆ドロップでボタン順を変更できます：タスクバーのトレイ領域で【編集モード】メニューから【オン】を選ぶか、
        任意のボタンを 3 秒長押しすると編集モードに入ります；
        ボタンを押したまま目標ボタンまでドラッグして離すと移動完了（iOS 風の挿入移動で他のボタンは繰り上がり）、
        離すと即時反映され ini ファイルに自動書き戻されます（[Button_XX] セクションの順序が画面表示順と一致、セクション内のコメント・空行・非表示ボタンの設定はそのまま保持、再起動不要）。
        調整後はトレイメニューで【編集モード-オフ】を選んで退出するか、ウィンドウ内の任意位置で右クリックすると即時退出できます。編集モードで 8 秒間順序変更がないと自動退出します；
        編集モード中にボタンをクリックしてもプログラムは起動しません。
  
      12.高解像度ディスプレイ（High DPI）表示に対応：PerMonitorV2 DPI 対応を有効化し、ディスプレイの実解像度で
        ネイティブ描画されるため、システムのビットマップ拡大によるぼやけがありません；ディスプレイ交換や OS の
        拡大率変更後はプログラムを再起動すると、ウィンドウとボタンは新しい拡大率に自動適応
        （Windows 10 1703 以上で有効）。

      13.ボタンは角丸キーキャップ風の立体スタイル（白い上面 + 下部の薄灰色側壁）：押すと上面が沈んで暗くなり、
        マウスをホバーするとボタン文字が上下にわずかに浮遊；ボタン文字が1行の幅に収まらない場合は空白の位置で自動で改行され、行数がボタンの高さを超える場合は末尾に ... を表示、手動改行は第 7 条の ini 例を参照。

      14.ボタン左上に起動プログラムのアイコンを自動表示：ini の Program_Name に設定されたプログラム（exe/cmd/bat/msc/lnk 等）
        のシステム関連アイコンを自動抽出して表示；裸のコマンド（shutdown、notepad 等）は PATH から自動検索；
        プログラムが存在しない未設定の場合はアイコン非表示；ini 変更後は自動再抽出、再起動不要；
        [System_Info] 節で MainForm_ShowProgramIcon=Off にするとアイコン表示をオフにできます（既定 On、保存後自動反映）。トレイの【プログラムアイコン】サブメニューでも切り替えでき、選択直後に反映され ini に書き戻されます。

      15.システムの明暗テーマ連動に対応：ini [System_Info] 節で MainForm_Theme=Auto/Light/Dark を設定
        （既定 Auto はシステムテーマに自動追従、システムが明暗を切り替えるとウィンドウも再起動不要でリアルタイムに追従）；
        トレイの【テーマ】メニュー（システムに従う/ライト/ダーク）でもいつでも切替可能、選択後即反映され ini に保存されます；
        ライトモードでは ini 設定のボタン背景色・文字色がそのまま適用され、ダークモードでは暗色系の見た目に自動変換されます
        （明示設定した色は色相を維持）；ダークモードではダイアログもダーク調に切り替わります。
