# QuickStart
자주 사용하는 프로그램과 명령을 한곳에 모은 퀵 실행 도구입니다.

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja-JP.md) · [English](README.en-US.md) · **한국어**

【빌드 환경】：

       Windows 11 Enterprise 26H2 (Cn) + Visual Studio 2026 Enterprise + .Net FrameWork 4.8

【실행 요구 사항】：

   .Net FrameWork 4.7.2 이상 설치 필요 (Windows 10 LTSC 2019/2021은 기본 포함; 그보다 오래된 시스템은 수동 설치)

   Download Url: [.NET Framework 4.7.2 다운로드 페이지](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net472)

【사용 방법】：
  
       1.ini 설정 파일을 편집하여 실행 프로그램의 실행 정보를 언제든지 변경할 수 있습니다.
       
       2.ini 파일 변경이 자동으로 반영됩니다: 실행 중.ini 파일을 계속 감시하며,
         외부에서 편집·저장하면 약 1초 이내에 자동 새로고침하여 단추를 갱신합니다
         (이름, 표시 여부, 사용 설정/해제, 색상, 프로그램 경로, 순서 등). 재시작이 필요 없습니다.
       
       3.ini 파일에 설정된 표시 단추 수에 따라 단추를 순서대로 자동 표시하며, 한 줄에 최대 8개, 초과분은 다음 줄에 자동 표시됩니다.
       
       4.단추는 최대 8줄 총 64개까지 표시 가능하며, 64개를 초과한 설정은 무시됩니다.
         구버전 ini(최대 48개)는 시작 시 누락된 [Button_49]~[Button_64] 섹션을 자동 보완합니다(기본 숨김).

       5.간체 중국어, 번체 중국어, 일본어, 한국어, 영어 5개 언어를 지원합니다.
       
       6.QQ 창과 유사한 화면 가장자리 붙기(도킹) 기능을 지원합니다.
  
       7.ini 파일 설정 예시：
        #############################################
        #[Button_01] - [Button_64] 최대 64개 단추 지원, 초과 시 무시
        [Button_XX]
        #단추 표시 이름【</br>, <br>, <br/> 또는 \n 으로 줄바꿈 표시 가능; 한 줄 너비를 넘는 글자는 공백에서 자동 줄바꿈되며, 줄 수가 단추 높이를 넘으면 끝에 ... 표시】
        Button_Name=
        #단추 표시 여부【1: 표시; 1이 아니면 숨김; 기본: 빈값 숨김】
        Button_Visible=
        #단추 사용 설정/해제【1: 사용; 1이 아니면 비활성; 기본: 빈값 비활성】
        Button_Enable=
        #단추 배경색【설정값은 영어 단어】
        Button_BackColor=
        #단추 글자색【설정값은 영어 단어】
        Button_TextColor=
        #실행할 프로그램의 전체 경로와 프로그램 이름
        Program_Name=
        #실행 유형【exe: exe 실행 파일; cmd: cmd 명령 또는 *.cmd, *.bat 실행 파일; 기본: exe】
        Program_Type=
        #실행 인수
        Program_Param=
        #############################################

        [Button_01]
        Button_Name=Eclipse<br/>v4.21
        Button_Visible=1
        Button_Enable=1
        Button_BackColor=GreenYellow
        Button_TextColor=OrangeRed
        Program_Name=D:\Eclipse_4.21\eclipse.exe
        Program_Type=exe
        Program_Param=-clean

      8.시스템 트레이 메뉴에서 자동 실행을 설정할 수 있습니다.

      9.이 프로그램은 동시에 하나만 실행할 수 있습니다.

      10.단추의 배경색과 글자색을 설정할 수 있습니다. (Sample_ini/Color.html 의 색 이름 참조)

      11.드래그 앤 드롭으로 단추 순서를 변경할 수 있습니다: 작업 표시줄 트레이 영역의【편집 모드】메뉴에서【켜기】를 선택하거나,
        아무 단추나 3초 길게 누르면 편집 모드로 진입합니다;
        단추를 누른 채 목표 단추까지 끌어 놓으면 이동 완료(iOS 스타일 삽입 이동, 다른 단추는 밀려남),
        놓으면 즉시 반영되고 ini 파일에 자동 기록됩니다 ([Button_XX] 섹션 순서가 화면 표시 순서와 일치,
        섹션 내 주석·빈 줄·숨김 단추 설정은 그대로 보존, 재시작 불필요).
        조정 후 트레이 메뉴【편집 모드-끄기】로 빠져나오거나, 창 내부 아무 곳에서나 마우스 오른쪽 버튼으로 클릭하면 즉시 종료됩니다. 편집 모드에서 8초간 순서 변경이 없으면 자동 종료됩니다;
        편집 모드에서 단추를 클릭해도 프로그램은 실행되지 않습니다.
  
      12.고해상도(High DPI) 디스플레이 표시 지원: PerMonitorV2 DPI 인식 활성화, 디스플레이의 실제 해상도로
        네이티브 렌더링되어 시스템 비트맵 확대로 인한 흐려짐이 없습니다; 디스플레이 교체 또는 OS 확대율 변경 후
        프로그램을 재시작하면 창과 단추가 새 확대율에 자동 적응합니다
        (Windows 10 1703 이상 필요).

      13.단추는 둥근 키캡 스타일의 입체 디자인(흰색 윗면 + 아래 옅은 회색 옆면): 누르면 윗면이 내려앉으며 어두워지고,
        마우스를 올리면 단추 글자가 위아래로 살짝 떠다닙니다; 단추 글자가 한 줄 너비를 넘는 경우 공백에서 자동 줄바꿈되며, 줄 수가 단추 높이를 넘으면 끝에 ... 표시, 수동 줄바꿈은 7항 ini 예시 참조.

      14.단추 좌측 상단에 실행 프로그램 아이콘 자동 표시: ini의 Program_Name에 설정된 프로그램(exe/cmd/bat/msc/lnk 등)
        의 시스템 연결 아이콘을 자동 추출하여 표시; 명령어만 입력한 경우(shutdown, notepad 등)는 PATH에서 자동 검색;
        프로그램이 없거나 미설정 시 아이콘 미표시; ini 변경 후 자동 재추출, 재시작 불필요;
        [System_Info] 섹션에서 MainForm_ShowProgramIcon=Off로 설정하면 아이콘 표시를 끌 수 있습니다(기본 On, 저장 후 자동 반영).

      15.시스템 명암 테마 추종 지원: ini [System_Info] 섹션에서 MainForm_Theme=Auto/Light/Dark 설정
        (기본 Auto는 시스템 테마 자동 추종, 시스템 명암 전환 시 창이 재시작 없이 실시간 추종);
        트레이의 【테마】 메뉴(시스템 설정/밝게/어둡게)로 언제든 전환 가능, 선택 즉시 반영되고 ini에 저장됨;
        라이트 모드에서는 ini 설정의 버튼 배경색·글자색이 그대로 적용되고, 다크 모드에서는 다크 톤으로 자동 변환됨
        (명시적으로 설정한 색은 색조 유지); 다크 모드에서는 대화상자도 다크 스타일로 전환됨.
