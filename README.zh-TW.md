# QuickStart
將常用的程式、命令集成在一起的快捷啟動軟體。

[简体中文](README.md) · **繁體中文** · [日本語](README.ja-JP.md) · [English](README.en-US.md) · [한국어](README.ko-KR.md)

【編譯環境】：

       Windows 11 Enterprise 26H2 (Cn) + Visual Studio 2026 Enterprise + .Net FrameWork 4.8

【運行要求】：

   需安裝 .Net FrameWork 4.7.2 及以上（Windows 10 LTSC 2019/2021 系統自帶；更舊的系統需自行安裝）

   Download Url: [.NET Framework 4.7.2 下載頁面](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net472)

【使用說明】：
  
       1.可修改ini設定檔，隨時修改可執行程式的啟動資訊。
       
       2.ini檔修改後自動生效：程式執行期間持續監視ini檔，外部修改儲存後約1秒內
         自動重新載入並重新整理按鈕（名稱、可見、可用、顏色、程式路徑、順序等），無需重啟程式。
       
       3.根據ini檔所設定可見按鈕個數，自動順序顯示按鈕。每行最多顯示 8 個，多的會自動顯示在下一行。
       
       4.按鈕最多可顯示 8 行，共 64 個按鈕，多於 64 個的設定會被忽略。
         舊版 ini（最多48個按鈕）啟動時自動補齊缺失的 [Button_49]~[Button_64] 段（預設不可見）。

       5.對簡體中文、繁體中文、日本語、韓國語、英語等五種語言文字提供支援。
       
       6.為操作方便，提供類似於QQ視窗的螢幕靠邊停靠功能。
  
       7.ini檔設定簡例：
        #############################################
        # [Button_01] - [Button_64] 最大支援64個按鈕，64個以上的忽略（無需改動）
        [Button_XX]
        # 按鈕顯示名稱【可用 </br>、<br>、<br/> 或 \n 實現文字換行顯示；文字超出一行寬度時在空格處自動換行，行數超過按鈕高度時末尾顯示 ...】
        Button_Name=
        # 按鈕是否可見【1：可見；1 以外不可見；預設：空 不顯示】
        Button_Visible=
        # 按鈕是否可用【1：可用；1 以外不可用；預設：空 不可用】
        Button_Enable=
        # 按鈕背景顏色【設定值為 英文單字】（可參照 Sample_ini/Color.html 的顏色名設定）
        Button_BackColor=
        # 按鈕文字顏色【設定值為 英文單字】（可參照 Sample_ini/Color.html 的顏色名設定）
        Button_TextColor=
        # 啟動程式的完整路徑和程式名
        Program_Name=
        # 程式啟動的類型【exe：exe可執行程式；cmd：cmd命令或者*.cmd、*.bat可執行程式；預設：exe】
        Program_Type=
        # 程式的啟動參數
        Program_Param=
        #############################################

        [Button_01]
        Button_Name=Eclipse<br/>v4.21
        Button_Visible=1
        Button_Enable=1
        Button_BackColor=GreenYellow
        Button_TextColor=OrangeRed
        Program_Name=D:\Eclipse_4.21\eclipse.exe
        Program_Type=exe
        Program_Param=-clean

      8.可在系統托盤選單列，設定開機自動啟動。

      9.本程式同時只能啟動一個執行個體。（若想啟動多個，可整個資料夾複製後，將複製後的 exe 檔改名）

      10.可設定按鈕背景顏色，按鈕文字顏色。（可參照 Sample_ini/Color.html 的顏色名設定）

      11.支援在介面上拖曳調整按鈕順序：在工作列托盤區【編輯模式】選單選擇【開】，
        或長按任意按鈕 3 秒，均可進入編輯模式；
        按住按鈕拖到目標按鈕上鬆開即可完成移動（iOS式插入移動，其餘按鈕順移），
        鬆手後立即生效並自動寫回ini檔（ini中[Button_XX]段順序與介面顯示順序保持一致，段內註解、空行及不可見按鈕設定原樣保留，無需重啟程式）。
        調整完畢後請在托盤選單選擇【編輯模式-關】退出編輯模式，或在視窗內任意位置點擊滑鼠右鍵立即退出，編輯模式下 8 秒未調整按鈕順序也會自動退出；
        編輯模式下點擊按鈕不會啟動程式。
  
      12.支援高解析度螢幕（High DPI）顯示：程式啟用PerMonitorV2 DPI感知，介面按顯示器實際解析度
        原生渲染，不再因系統位圖拉伸而模糊；更換顯示器或調整系統縮放比例後重新啟動程式，
        視窗與按鈕自動按新縮放比例適配（Windows 10 1703及以上系統生效）。

      13.按鈕為圓角鍵帽立體樣式（白色頂面 + 底部淺灰側壁）：按下時頂面下沉變暗，
        滑鼠游標停留時按鈕文字上下輕微浮動；按鈕文字超出一行寬度時在空格處自動換行，行數超過按鈕高度時末尾顯示 ...，手動換行見第 7 條 ini 範例說明。

      14.按鈕左上角自動顯示啟動程式的圖示：根據 ini 中 Program_Name 設定的程式（exe/cmd/bat/msc/lnk 等）
        自動擷取系統關聯圖示顯示；裸命令（如 shutdown、notepad）依 PATH 自動尋找對應程式；
        程式不存在或未設定時不顯示圖示；ini 修改後自動重新擷取，無需重啟；
        可在 [System_Info] 段設定 MainForm_ShowProgramIcon=Off 關閉圖示顯示（預設 On，修改儲存後自動生效）；亦可透過託盤【程式圖示】選單隨時開/關，選擇後立即生效並寫回 ini。

      15.支援跟隨系統明暗主題：ini [System_Info] 段 MainForm_Theme=Auto/Light/Dark（預設 Auto 自動跟隨
        系統主題，系統切換明暗時視窗即時跟隨，無需重新啟動）；亦可透過託盤【主題】選單隨時切換
        （跟隨系統/淺色/深色），選擇後立即生效並寫回 ini；亮色模式下 ini 設定的按鈕背景色與文字顏色
        原樣生效，暗色模式下自動轉換為暗色系觀感（顯式設定的顏色保留原色調）；暗色模式下彈窗同步採用暗色風格。
