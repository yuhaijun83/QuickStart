# QuickStart
把常用的程序、命令集成在一起的快捷启动软件。

**简体中文** · [繁體中文](README.zh-TW.md) · [日本語](README.ja-JP.md) · [English](README.en-US.md) · [한국어](README.ko-KR.md)

【编译环境】：

       Windows 11 Enterprise 26H2 (Cn) + Visusl Studio 2026 Enterprise + .Net FrameWork 4.8

【运行要求】：

   需安装 .Net FrameWork 4.7.2 及以上（Windows 10 LTSC 2019/2021 系统自带；更老的系统需自行安装）

   Download Url: [.NET Framework 4.7.2 下载页面](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net472)

【使用说明】：
  
       1.可修改ini配置文件，随时修改可执行程序的启动信息。
       
       2.ini文件修改后自动生效：程序运行期间持续监视ini文件，外部修改保存后约1秒内
         自动重新加载并刷新按钮（名称、可视、可用、颜色、程序路径、顺序等），无需重启程序。
       
       3.根据ini文件所配置的可视按钮个数，自动顺序显示按钮。每行最多显示 8 个，多的会自动显示在下一行。
       
       4.按钮最多可显示 8 行，共 64 个按钮，多于 64 个的配置会被忽视。
         旧版 ini（最多48个按钮）启动时自动补齐缺失的 [Button_49]~[Button_64] 段（默认不可视）。

       5.对简体中文、繁体中文、日本语、韩国语、英语等五种语言文字提供支持。
       
       6.为操作方便，提供类似于QQ窗体的屏幕靠边停靠功能。
  
       7.ini文件配置简例：
        #############################################
        #[Button_01] - [Button_64] 最大支持64个按钮，64个以上的忽视
        [Button_XX]
        #按钮显示名称【可用 </br>、<br>、<br/> 或 \n 实现文字换行显示；文字超出一行宽度时在空格处自动换行，行数超过按钮高度时末尾显示 ...】
        Button_Name=
        #按钮是否可视【1：可视；1 以外不可视；默认：空 不显示】
        Button_Visible=
        #按钮是否可用【1：可用；1 以外不可用；默认：空 不可用】
        Button_Enable=
        #按钮背景颜色【设定值为 英文单词】
        Button_BackColor=
        #按钮文本颜色【设定值为 英文单词】
        Button_TextColor=
        #启动程序的完整路径和程序名
        Program_Name=
        #程序启动的类型【exe：exe可执行程序；cmd：cmd命令或者*.cmd、*.bat可执行程序；默认：exe】
        Program_Type=
        #程序的启动参数
        Program_Param=
        #############################################

        [Button_01]
        Button_Name=Eclipse<br/>v4.21
        Button_Visible=1
        Button_Enable=1
        Button_BackColor=GreenYellow
        Button_TextColor=OrangeRed
        Program_Name=D:\Eclipse_4.21\eclipse.exe
        Program_Type=exe
        Program_Param=-clean

      8.可在系统托盘菜单栏，设置开机自动启动。

      9.本程序同时只能启动一个实例。

      10.可设置按钮背景颜色，按钮文本颜色。（可参照 Sample_ini/Color.html 的颜色名设置）

      11.支持在界面上拖拽调整按钮顺序：在任务栏托盘区【编辑模式】菜单选择【开】，
        或长按任意按钮 3 秒，均可进入编辑模式；
        按住按钮拖到目标按钮上松开即可完成移动（iOS式插入移动，其余按钮顺移），
        松手后立即生效并自动写回ini文件（ini中[Button_XX]段顺序与界面显示顺序保持一致，
        段内注释、空行及不可视按钮配置原样保留，无需重启程序）。
        调整完毕后请在托盘菜单选择【编辑模式-关】退出编辑模式，或在窗体内任意位置点击鼠标右键立即退出，
        编辑模式下 8 秒未调整按钮顺序也会自动退出；
        编辑模式下点击按钮不会启动程序。
  
      12.支持高分屏（High DPI）显示：程序启用PerMonitorV2 DPI感知，界面按显示器实际分辨率
        原生渲染，不再因系统位图拉伸而模糊；更换显示器或调整系统缩放比例后重新启动程序，
        窗口与按钮自动按新缩放比例适配（Windows 10 1703及以上系统生效）。

      13.按钮为圆角键帽立体样式（白色顶面 + 底部浅灰侧壁）：按下时顶面下沉变暗，
        鼠标悬停时按钮文字上下轻微浮动；按钮文字超出一行宽度时在空格处自动换行，行数超过按钮高度时末尾显示 ...，手动换行见第 7 条 ini 示例说明。

      14.按钮左上角自动显示启动程序的图标：根据 ini 中 Program_Name 配置的程序（exe/cmd/bat/msc/lnk 等）
        自动提取系统关联图标显示；裸命令（如 shutdown、notepad）按 PATH 自动查找对应程序；
        程序不存在或未配置时不显示图标；ini 修改后自动重新提取，无需重启；
        可在 [System_Info] 段设置 MainForm_ShowProgramIcon=Off 关闭图标显示（默认 On，修改保存后自动生效）；也可通过托盘【程序图标】菜单随时开/关，选择后立即生效并写回 ini。

      15.支持跟随系统明暗主题：ini [System_Info] 段 MainForm_Theme=Auto/Light/Dark（默认 Auto 自动跟随
        系统主题，系统切换明暗时窗体实时跟随，无需重启）；也可通过托盘【主题】菜单随时切换
        （跟随系统/浅色/深色），选择后立即生效并写回 ini；亮色模式下 ini 配置的按钮背景色与文字颜色
        原样生效，暗色模式下自动转换为暗色系观感（显式配置的颜色保留原色相）；暗色模式下弹框同步采用暗色风格。
